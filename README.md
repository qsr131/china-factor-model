# 中国因子模型数据 · 发布包（含「指数 × 因子 对比分析」）

首页（移动端壳）四张卡片，第 4 张「指数 × 因子 对比分析」在页内弹层打开对比页。

## 对比页的三大板块

1. **因子定义与计算公式**（顶部可折叠卡片）：按当前数据源显示 Mkt−RF / SMB / HML / RMW / CMA / UMD（FF 五因子）或 Mkt / SMB / VMG（CH-3）、再加 PMO（CH-4）的构造公式与分组规则，附文献出处。
2. **对比指数 / 行业下拉框**：宽基指数 6 个 + 中证一级行业 10 个 + 东方财富细分行业 100 个，共 116 个序列（月度全历史 + 日度 2024 起）。
3. **图③ 滚动相关系数 + 显著性柱**：半透明柱 = 1 − p（Pearson r 的双侧 t 检验，t = r·√((n−2)/(1−r²))，df = n−2）。0.95 即 p = 0.05，柱子越高越显著；右上角按钮可开/关。悬停提示里会给出每个点的 r、p 与是否显著。

## 行业口径说明（重要）

用户要的是**证监会一级/二级行业指数**（A00000 系列）。这套指数只在 Wind / PTrade（`.XBHS`）等终端有历史行情，公开接口（东方财富、中证指数、巨潮）都取不到，所以本应用用两个公开可得的行业口径替代：

- **中证一级行业**：000928 能源 / 000929 材料 / 000930 工业 / 000931 可选消费 / 000932 主要消费 / 000933 医药卫生 / 000934 金融 / 000935 信息技术 / 000936 通信服务 / 000937 公用事业
- **东方财富细分行业**：BK 板块 100 个，粒度接近二级行业

若以后有证监会行业指数的数据源，改 `build_data.mjs` 的 `CSI_L1`/`boards` 部分即可，页面无需改动。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 应用首页（四张卡片 + 对比页弹层） |
| `compare.html` | 对比分析页（公式 / 三图 / 行业下拉 / 显著性柱） |
| `factor_data.js` | 首页因子数据（6 个数据集） |
| `data_all.js` | 对比页数据（116 个指数/行业 + 因子，约 4 MB） |
| `echarts.min.js` | 本地 ECharts 5，不依赖 CDN |

## 更新数据

```bash
node factor-app-tools/build_data.mjs "<本文件夹路径>"
```

拉东方财富指数/行业行情 + 复用 `factor_data.js` 里的因子数据，重写 `data_all.js`，然后重新发布。

## 本地预览

双击 `index.html` 即可（弹层里的对比页用 iframe 指向 `compare.html`，同一文件夹内即可离线工作）。
